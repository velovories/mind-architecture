# Mind Architecture

Плагин для Obsidian, который помогает думать заметками, а не просто хранить их.
Плагін для Obsidian, який допомагає думати нотатками, а не просто зберігати їх.

Интерфейс на русском или украинском — переключается в настройках плагина.
Інтерфейс російською або українською — перемикається в налаштуваннях плагіна.

## Что умеет / Що вміє

- **Сегодня / Сьогодні** — пара заметок, похожих по словам, но далёких в графе, с вопросом для размышления; список голых ссылок, запланированных тем и заметок-сирот.
- **Связи / Зв'язки** — боковая панель текущей заметки: какие ссылки объяснены, какие нет, что ещё может быть связано и почему.
- **Почему они связаны? / Чому вони пов'язані?** — одна строка в заметке: `[[Заметка]] — аналогия: …`. Пишется только по кнопке.
- **Качество мышления / Якість мислення** — доля объяснённых связей, выводы, сироты.

Всё работает на устройстве, без ИИ и без интернета. Ни одна заметка никуда не отправляется.
Усе працює на пристрої, без ШІ та без інтернету. Жодна нотатка нікуди не надсилається.

## Установка через BRAT / Встановлення через BRAT

1. Community plugins → BRAT → установить и включить.
2. BRAT → Add beta plugin → `velovories/mind-architecture`.
3. Включить Mind Architecture в списке плагинов.

## Разработка

```bash
npm install
npm test        # ядро проверяется без Obsidian
npm run build   # main.js
```
